# Distribution boundary

## Student deliverable
README / scenario, EDUCATIONAL_USE_AND_ETHICS.md, validated artifacts.zip, evidence_manifest.json, question prompts and tool-neutral setup instructions.

## Instructor-only
Validated answers, proof values, walkthrough, exact offsets, authoring scripts if they expose expected answers, QA and playtest notes. Keep private and do not include in student archive.

## Pre-release audit
- Inspect all ZIP entries for answer keys, proof tokens, personal data and credentials.
- Recompute SHA-256 from the final ZIP and compare to manifest.
- Verify that each question can be solved using **only** the student deliverable.
- Document which items are simulation exports versus native forensic formats.
- Ensure educational notice appears in the student ZIP and landing README.
